# Layout

Where things are in this repo (moved out of `CLAUDE.md` on 2026-10-26 so that it is read when needed,
not loaded with every message). Add or change a row when a file or folder is added, moved or changes purpose.

This table says where things are, not how many: counts live in the files that are regenerated or updated with
them (`tests\*\README.md`, `STATUS.md`'s numbers), and catalogues in their folder's `README.md` (ninth review,
`study\archive\30` §2).
