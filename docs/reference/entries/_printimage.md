# _PRINTIMAGE

`_PRINTIMAGE handle` prints an image on the printer.

## Syntax

```text
_PRINTIMAGE handle
```

## Behavior

`_PRINTIMAGE` compiles to QB64pe's call. No test runs it, since the tests have no printer.
