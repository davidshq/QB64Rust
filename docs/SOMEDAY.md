# Someday

Features and ideas deliberately left out of the first versions of the rewrite. Each entry says why it was deferred
and where the details are. Nothing here is rejected; it is just not on the roadmap yet.

The first column of each table is the row's priority from the user, P1 (highest) to P5 (lowest), given from
2026-11-07. An empty cell means no priority has been given yet.

The second column names a group: rows that touch the same subject and are best built together, as one change
(added 2026-11-09). The same name stands in each row of a group, in any table; a row of two groups names both.
An empty cell means the row stands alone. Rows point at each other by group, not by "the row above", so that
they can be sorted or moved.

## Popular BASIC PDS 7.1 features

Not planned yet (user, 2026-11-04). Microsoft BASIC PDS 7.1 added features that QuickBASIC 4.5 does not have, and
QB64pe never took most of them. Old programs written for PDS use them, so each one is an edit a port has to make.
The World War 2 port (2026-11-04) hit `DIR$` 16 times, `ON LOCAL ERROR` once and `CURDIR$` twice. The port
missed the `CURDIR$` calls at first, because both compilers build them without a message.

This would be a language extension: QB64pe rejects these forms. A program that uses them would no longer build
with QB64pe. So it needs a decision first, and probably a switch of its own, as for names of more than 40
characters ("Other ideas raised during the study").

The list is from memory of PDS 7.1, most popular first. Only the `DIR$`, `ON LOCAL ERROR` and `CURDIR$` rows are
measured.
Before one is built, measure what QB64pe does with the form, and measure what PDS does: since 2026-11-05,
`qb45.py --compiler pds71` builds and runs a program with PDS 7.1 (`tools\qb45\README.md`, "PDS 7.1").

| Priority | Group | Feature | What a port does today | Notes |
|---|---|---|---|---|
| P3 | pds-switch | `DIR$(spec$)` and `DIR$` with no argument for the next match | Writes its own FUNCTION with `_FILES$`; a call with no argument becomes `DIR$("")` | The most common one: almost every PDS program with a file menu has it. QB64pe has no `DIR$` (measured by the port) |
| P3 | pds-switch | `REDIM PRESERVE` | Renames it to `REDIM _PRESERVE` | The same behavior under QB64's name, so it is only a second spelling |
| P2 | lints | A warning for a PDS-only function read as a variable (`CURDIR$` with no arguments) | Finds them by hand, or not at all: the World War 2 port missed two `CURDIR$` calls at first | **The danger is silence:** QB64pe and QB64Rust both build a bare `CURDIR$` as a string variable that is always `""`, with no message (measured 2026-11-05, World War 2 port). A warning would name it: "`CURDIR$` is a BASIC PDS 7.1 function; QB64 reads it as a variable". It changes no program, so it needs no PDS switch. The same check fits any PDS-only function that a program can call with no arguments |
| P3 | pds-switch | `CURDIR$` and `CHDRIVE` | Writes a `FUNCTION CURDIR$` that returns `_CWD$` without its last separator; uses `CHDIR` for `CHDRIVE` | `CURDIR$` can take a drive letter. PDS gives `C:\GAMES`, with no separator at its end unless it is a root. `_CWD$` ends with one. The warning for a bare `CURDIR$` is a row of its own in this table, outside the group: it needs no switch |
| P5 | pds-switch | The `CURRENCY` type: the `@` suffix, `DEFCUR`, `CCUR`, `CVC`, `MKC$` | Changes the variables to `DOUBLE` or `_INTEGER64` and rewrites the rounding | Common in business programs. A 64-bit integer scaled by 10,000. The largest row here: a new type through the whole compiler, and a record format in `GET` and `PUT` |
| P4 | pds-switch | `ON LOCAL ERROR GOTO` in a SUB or FUNCTION | Moves the handler to the main module or removes it | QB64pe rejects it with "Name already in use (ERROR)", in a SUB and in the main module (`verification\v17_d_err_on_local_error_sub`, `_main`). Since 2026-11-05 our error says to use `ON ERROR GOTO` with the handler in the main module, and `ON ERROR GOTO 0` before the SUB ends: a handler set in a SUB stays active after it returns (`verification\v17_d_on_error_sub_stays`) |
| P4 |  | Measure that a `TYPE` with a fixed member array (`a(1 TO 3) AS INTEGER`) has the same bytes in a `GET` or `PUT` file in PDS 7.1 as here | Keeps the member as PDS writes it: fixed member arrays compile and run without a switch (2026-11-08: `x.a(2) = 7` prints 7 and `LEN` is 8 for an INTEGER beside three INTEGERs) | Only the layout in a file is not measured. | P3 | pds-switch | `BYVAL` parameters of a BASIC SUB or FUNCTION | Removes `BYVAL` and copies the parameter by hand | QB64pe allows `BYVAL` only in `DECLARE LIBRARY` |
| P4 |  | The add-on libraries: `FORMAT$`, the date serial functions (`DateSerial`, `Now` and the others), the financial functions | Writes its own | These are libraries, not statements; they could ship as `.bi`/`.bm` files instead of built-ins. something in DOS memory) and the toolbox sources (`MOUSE.BAS`, `MENU.BAS`, `WINDOW.BAS`), which are BASIC code
that compiles once `CALL INTERRUPT` does ("Deferred QB64pe features").
