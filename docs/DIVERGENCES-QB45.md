# Divergences from QuickBASIC 4.5

Where QB64Rust behaves differently from QuickBASIC 4.5. The companion of `QB64PE-DIVERGENCES.md`, which registers the
differences from the old compiler (QB64pe); QB64Rust follows QB64pe where the two differ unless a row there says
otherwise, so most rows here are differences QB64Rust inherits from QB64pe. A row is added when a behaviour is
decided and QB 4.5 is known or believed to differ (decided 2026-10-07, user).

QB 4.5 runs on the development machine under DOSBox since 2026-10-26 (`tools\qb45\README.md`; QB 4.5 itself is
outside the repo). Each row says where its QB 4.5 behaviour comes from: **documented** (Microsoft's QB 4.5 manuals
or help), **believed** (from memory of how QB 4.5 works, not checked), or **measured** (built with QB 4.5's `BC` and
run under DOSBox, with the program in `verification\qb45\`). Rows that are not measured can now be checked with
`tools\qb45\qb45.py`.

BASIC PDS 7.1 runs the same way since 2026-11-05 (`qb45.py --compiler pds71`; PDS 7.1 is outside the repo too). A
row that cites a `<name>.pds71.txt` was measured with PDS 7.1 as well, for programs ported from PDS.
