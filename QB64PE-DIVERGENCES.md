# Divergence register

Every intentional difference between QB64Rust and the observed behaviour of the old compiler (QB64pe 4.7.0,
`16f629784e`, Windows). A row is added only when a difference has been **decided**; open choices stay in
`study\00` §6 until then (all of them were decided on 2026-10-08). The numeric rules themselves are the spec
`openspec\specs\language\numeric-semantics`. A row whose "Pinned by" says "not yet" is decided but not implemented:
until it is, the new compiler marks the case "not supported yet" or behaves as the old one, as the row says.

**The run-time trace** (`m3-divergence-trace`): a program built by the new compiler writes `D-0nn` to the file
`QB64RUST_DIVERGENCES` names the first time in a run that it takes the path of a row; the test runner sets the
variable for every run and fails a program whose `<name>.divergences` sidecar does not list the row, and each
row's CLI test names the rows its program takes. Traced: D-003, D-004, D-006, D-016, D-018–D-022, D-031, D-036, D-037, D-040, D-042, D-045, D-046; D-003 and D-004,
which differ only in a program that goes on after the error, are not written where libqb will end the program
(no handler and `QB64PE_NOPROMPT=y`, or a critical error; CLI test `an_error_that_ends_the_program_traces_nothing`).
No run-time
path: D-001, D-002, D-005, D-009, D-014, D-025, D-043, D-044, D-047, D-054 (the C++ differs, no branch is taken), D-007,
D-008, D-015, D-017, D-026–D-030, D-033–D-035, D-041 (compile time; D-026 is shown by a warning with `-w`), D-010–D-013
(not built), D-048–D-053 (in libqb, which cannot call the generated program's `qbr_diverged`). A new row with a
run-time path comes with its `qbr_diverged` call.

"Default" is the old compiler's normal build; "`-O2`" is its build with "optimize C++" on
(`-f:OptimizeCppProgram=true`). Where they behave the same only one value is given.
