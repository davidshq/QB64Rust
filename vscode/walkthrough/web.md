# Put your program on the web (optional)

A program with a window can run in a web browser. Click **Run in Browser**: the program is built for a web page and
opens in your browser, served from this computer only.

It needs the Emscripten SDK, an 815 MB download that the first run asks for. The folder `build/web` is then the
web page, ready to upload to a web host.

A program with `$CONSOLE:ONLY` has no web page.
