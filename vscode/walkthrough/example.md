# Try an example

The side panel's **Examples** view has programs to run and change: first steps, graphics, sound and small games.
Click **Open an Example** to open "Guess the number" in a new editor. Run it, then change a number in it and run
it again to see what the change does.

An example opens as a copy of your own: what you change is kept in it. Right-click the example and choose **Reset
This Example** to get the first text back.
