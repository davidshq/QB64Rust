# Run it

Click **Run**, here, in the side panel's Program view, or at the left of the status bar. The program is built and
starts in a terminal named "QB64".

**The first run needs a C++ compiler.** QB64 turns your program into C++ and builds it with one. If QB64pe is not
installed, the first run asks whether to download one: a 190 MB download from github.com/mstorsjo/llvm-mingw.
Nothing is downloaded unless you agree, and it is downloaded only once.

The first build also builds the QB64 runtime once, which takes a little longer. The Program view says when it does.
