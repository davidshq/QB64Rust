# Run it

Click **Run**, here, in the side panel's Program view, or at the left of the status bar. The program is built and
starts in a terminal named "QB64".

**The build uses your system's `g++`.** QB64 turns your program into C++ and builds it with the system's C++
compiler. If `g++` or a library is missing, the first run says which packages to install; nothing is downloaded.

The first build also builds the QB64 runtime once, which takes a little longer. The Program view says when it does.
