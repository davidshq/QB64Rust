# Write your first program

A program is a list of statements that the computer carries out from the top. Click **New Program**: a save dialog
asks where to keep the file and what to call it, and the new file opens with one line in it:

```
PRINT "Hello, world!"
```

Change the text between the quotes, or add a line such as `PRINT 2 + 3`.

The QB64 icon at the left of the window opens the side panel, where the **Program** view shows the program you are
writing.
