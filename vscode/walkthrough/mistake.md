# Find and fix a mistake

Click **Open a Program with a Mistake**. It opens "Hello" with a mistake on line 3: a `(` that is never closed.

- The mistake is underlined in red as soon as the file opens.
- The side panel's **Program** view shows the first error with its line and a **Go to line 3** link, and the
  status bar shows "1 error: line 3".

Add the missing `)` at the end of line 3. The underline goes, and the Program view says "OK".
