# Divergence register

Every intentional difference between QB64Rust and the observed behaviour of the old compiler (QB64pe 4.7.0,
`16f629784e`, Windows). A row is added only when a difference has been **decided**; open choices stay in
`study\00` §6 until then (all of them were decided on 2026-10-08). The numeric rules themselves are the spec
`openspec\specs\language\numeric-semantics`. A row whose "Pinned by" says "not yet" is decided but not implemented:
until it is, the new compiler marks the case "not supported yet" or behaves as the old one, as the row says.

"Default" is the old compiler's normal build; "`-O2`" is its build with "optimize C++" on
(`-f:OptimizeCppProgram=true`). Where they behave the same only one value is given.

D-001 and D-002 differ from the old compiler only in its `-O2` build; the corpus is recorded with the default build,
so these programs pass unchanged. D-003 differs only after a program would have crashed. D-004 differs only after an
error 9 the program chose to ignore. D-015 is the wording of one error. D-005 to D-014, D-016 and D-018 to D-021 change what a program the old compiler builds does only where
it crashes, hangs, corrupts memory (D-014: reads released memory; D-016: reads an array's data as a lock; D-019
and D-020: write past a block's end; D-021: reads through a missing descriptor or a buffer that holds nothing read) or
computes a value by a slip (D-005, D-007); D-008 and D-013 accept programs the
old compiler rejects. D-017 leaves out what only the old compiler's IDE uses, and accepts the programs that name
what it leaves out.
